# 학습일지 — 2026-08-14

## 오늘 실습한 내용

RM75 실기체를 이용하여 물체를 A 위치에서 집어
B 위치로 옮기는 Pick-and-Place 동작을 실습하였다.

먼저 RViz에서 RM75의 움직임을 확인하고,
실기체에서 `MoveJ_P`, `MoveL`, 그리퍼 명령을 이용하여
물체 접근, 파지, 이동, 내려놓기를 수행하였다.

---

## 1. 물체 접근

먼 거리에서 물체 방향으로 이동할 때는 `MoveJ_P`를 사용하였다.

A 위치는 물체의 실제 위치에 맞추어
x 방향 값을 약 `0.30`으로 사용하였고,
물체 위 접근 위치에서는 z 방향으로 약 `0.10`의 값을 사용하였다.

물체 가까이에서는 `MoveL`을 사용하여
그리퍼가 물체 방향으로 직선으로 내려가도록 하였다.

즉,

`MoveJ_P로 물체 위 접근 → MoveL로 수직 하강`

순서로 물체에 접근하였다.

---

## 2. MoveJ_P 실행 중 발생한 문제

처음에는 초기 자세에서 바로 `MoveJ_P`를 실행했지만
정상적으로 목표 위치까지 이동하지 않았다.

그래서 RM75의 IP 조작 화면에 접속하여
로봇을 물체 쪽으로 조금 더 가까운 위치까지 직접 이동시켰다.

그 후 다시 `MoveJ_P`를 실행하자 정상적으로 동작하였다.

이를 통해 목표 좌표만 설정하는 것뿐만 아니라
현재 로봇의 자세에서 목표 위치까지 이동할 수 있는지도
중요하다는 것을 확인하였다.

한 번에 목표점으로 이동하기 어려운 경우에는
안전한 중간 자세를 거쳐 이동하는 방법이 필요하다는 것을 배웠다.

---

## 3. 그리퍼 파지력 조정

처음에는

- Speed: 200
- Force: 300

으로 물체를 파지하였다.

물체를 잡는 것 자체는 가능했지만,
잡은 상태에서 이동할 때 파지가 약간 불안정하게 느껴졌다.

따라서 Speed는 200으로 그대로 유지하고
Force만 `300 → 500`으로 변경하였다.

Force 500으로 다시 같은 동작을 수행한 결과,
물체가 찌그러지지 않으면서 더 안정적으로 파지되었다.

따라서 이번 물체에서는

**Speed 200 / Force 500**

을 최종 파지값으로 사용하였다.

---

## 4. A → B 이동

A 위치에서 물체를 파지한 후 들어 올려
B 위치로 이동하였다.

B 위치에서 사용한 값은 다음과 같다.

- x: `0.30`
- y: `0.14`
- z: `0.01`

A 위치에서 물체를 잡은 후
B 위치로 이동하여 내려놓는 동작까지 수행하였다.

---

## 5. 전체 동작 순서

이번 실습에서 수행한 Pick-and-Place 과정은 다음과 같다.

1. 초기 자세에서 시작
2. 필요할 경우 IP 조작 화면에서 중간 자세로 이동
3. `MoveJ_P`로 A 위치 위까지 접근
4. `MoveL`로 수직 하강
5. Speed 200 / Force 500으로 물체 파지
6. 물체를 들어 올림
7. A에서 B 위치로 이동
8. B 위치로 하강
9. 그리퍼를 열어 물체 내려놓기
10. 다시 상승
11. 초기 자세로 복귀

---

## 주의할 점

- 초기 자세에서 목표 위치로 바로 이동되지 않을 수 있으므로 현재 로봇 자세를 확인한다.
- 한 번에 이동하기 어려운 경우 안전한 중간 자세를 사용한다.
- 물체 가까이에서는 옆으로 접근하기보다 위에서 수직으로 접근한다.
- 물체를 잡은 뒤 바로 옆으로 움직이기보다 먼저 충분히 들어 올린 후 이동한다.
- 파지력이 너무 약하면 이동 중 물체를 놓칠 수 있고, 너무 강하면 물체가 변형될 수 있다.
- 이번 물체에서는 Force 500에서 변형 없이 안정적으로 파지할 수 있었다.

---

## 배운 점

이번 실습을 통해 Pick-and-Place에서는
단순히 A와 B 좌표만 정하는 것이 아니라
현재 로봇의 자세와 접근 경로를 함께 고려해야 한다는 것을 알게 되었다.

특히 처음 `MoveJ_P`가 정상적으로 실행되지 않았을 때
IP 조작 화면을 이용해 중간 자세를 만든 후 다시 실행하여 해결하였다.

또한 먼 거리 이동에는 `MoveJ_P`,
물체 가까이에서 수직으로 접근할 때는 `MoveL`을 사용하는 방법을
실기체에서 직접 확인하였다.

그리퍼도 Force 300과 500을 직접 비교해 보면서
물체를 찌그러뜨리지 않으면서 안정적으로 이송할 수 있는
파지 조건을 찾는 것이 중요하다는 것을 확인하였다.

## 시퀀스 표

| 구간 | 동작 (목표 지정 방법) | 값 (좌표·폭·힘) | 성공 확인 |
|---|---|---|---|
| 출발 | 초기 자세(Home) | - | 초기 자세 확인 |
| ① | A 위 접근 자세 (`MoveJ_P`) | x=0.30, y≈0, z=0.10 / orientation은 기준 pose 사용 | 처음에는 바로 이동되지 않았지만, IP 조작 화면에서 로봇을 물체 가까이 이동시킨 뒤 재실행하여 성공 |
| ② | 파지 자세로 수직 하강 (`MoveL`) | A 위치에서 물체 방향으로 수직 하강 | 그리퍼가 물체 위치에 맞게 수직으로 내려가는 것을 확인 |
| ③ | 그리퍼 파지 | Speed=200, Force=500 | 물체가 찌그러지지 않고 안정적으로 파지됨 |
| ④ | 들어올림 → B 위치로 이동 | B: x=0.30, y=0.14, z=0.01 | 물체를 놓치지 않고 A에서 B로 이동 성공 |
| ⑤ | B 위치 하강 → 그리퍼 열기 → 상승 | B 위치에서 수직 하강 후 그리퍼 Open | 물체를 B 위치에 내려놓음 |
| 복귀 | 초기 자세(Home) | - | 초기 자세로 복귀 |
