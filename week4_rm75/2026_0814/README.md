# 7.2 실습 — RM75 Pick-and-Place

## 시퀀스 표

| 구간 | 동작 (목표 지정 방법) | 값 (좌표·폭·힘) | 성공 확인 |
|---|---|---|---|
| 출발 | 초기 자세(Home) | - | 초기 자세 확인 |
| ① | A 위 접근 자세 (`MoveJ_P`) | x=0.30, y≈0, z=0.10 / orientation은 기준 pose 사용 | 처음에는 바로 이동되지 않았지만, IP 조작 화면에서 로봇을 물체 가까이 이동시킨 뒤 재실행하여 성공 |
| ② | 파지 자세로 수직 하강 (`MoveL`) | A 위치에서 물체 방향으로 수직 하강 | 그리퍼가 물체 위치에 맞게 수직으로 내려가는 것을 확인 |
| ③ | 그리퍼 파지 | Speed=200, Force=500 | 물체가 찌그러지지 않고 안정적으로 파지됨 |
| ④ | 들어올림 → B 위치로 이동 | B: x=0.30, y=0.14, z=0.01 | 물체를 놓치지 않고 A에서 B로 이동 성공 |
| ⑤ | B 위치 하강 → 그리퍼 열기 → 상승 | B 위치에서 수직 하강 후 그리퍼 Open | 물체를 B 위치에 내려놓음 |
| 복귀 | 초기 자세(Home) | - | 초기 자세로 복귀 |
