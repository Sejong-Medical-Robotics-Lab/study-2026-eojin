# RM75 Pick-and-Place 실기체 학습일지 — 2026-08-14

## Pick-and-Place 시퀀스 표

| 구간 | 동작 (목표 지정 방법) | 값 (좌표·폭·힘) | 성공 확인 |
|---|---|---|---|
| 출발 | 초기 자세(Home) | - | 초기 자세 확인 |
| ① | A 위 접근 (`MoveJ_P`) | x=0.30, y≈0, z=0.10 / orientation은 기준 pose 사용 | A 위치 위까지 이동 성공 |
| ② | 파지 자세로 수직 하강 (`MoveL`) | A 위치에서 수직 하강 | 물체 중앙에 그리퍼 정렬 |
| ③ | 그리퍼 파지 | Speed=200, Force=500 | 물체가 찌그러지지 않고 안정적으로 파지됨 |
| ④ | 물체 들어올림 → B 위치로 이동 | B: x=0.30, y=0.14, z=0.01 | 물체를 놓치지 않고 B 위치로 이동 |
| ⑤ | B 위치 하강 → 그리퍼 열기 → 상승 | B 위치에서 수직 하강 후 Open | 물체를 B 위치에 내려놓음 |
| 복귀 | 초기 자세(Home) 복귀 | - | 초기 자세 도달 |

---

## 기준 Pose

실습에서 참고한 pose는 다음과 같다.

```yaml
position:
  x: 0.3838
  y: 0.000003
  z: 0.6258

orientation:
  x: 0.0
  y: 0.68127
  z: 0.0
  w: 0.73203
```

실제 Pick-and-Place에서는 물체의 위치에 맞게 좌표를 수정하여 사용하였다.

- A 위치 x: 약 `0.30`
- A 접근 높이 z: 약 `0.10`
- B 위치 x: `0.30`
- B 위치 y: `0.14`
- B 위치 z: `0.01`
- Gripper Speed: `200`
- Gripper Force: `500`

# 학습일지

## 1. RViz에서 RM75 동작 확인

먼저 RViz에서 RM75를 움직여 보면서 로봇팔의 자세 변화와 이동을 확인하였다.

시뮬레이션에서 로봇이 목표 위치에 따라 어떤 자세를 만드는지 확인한 후
실기체 Pick-and-Place 실습을 진행하였다.

---

## 2. 물체 위치 및 거리 확인

실습에 사용한 그리퍼의 길이는 약 `17 cm`였다.

RM75와 물체 사이 거리는 약 `38 cm` 정도로 확인했지만,
실제 로봇 동작에서는 물체 위치에 맞추어 x 방향 값을 약 `0.30`으로 사용하였다.

처음부터 물체에 바로 접근하지 않고,
물체 위쪽의 안전한 위치를 목표로 설정한 뒤 수직으로 내려가는 방식으로 진행하였다.

---

## 3. A 위치 접근

A 위치의 물체에 접근할 때 먼저 `MoveJ_P`를 사용하였다.

주요 접근 값은 다음과 같다.

- x: 약 `0.30`
- z 접근 높이: 약 `0.10`

먼 거리 이동에는 `MoveJ_P`를 사용하고,
물체 위에 도착한 뒤 실제 파지를 위해 내려갈 때는
`MoveL`을 사용하여 수직으로 하강하였다.

동작 흐름:

`Home → MoveJ_P로 A 위 접근 → MoveL 수직 하강 → 파지`

---

## 4. MoveJ_P 실행 중 발생한 문제

처음에는 초기 자세에서 바로 `MoveJ_P`를 실행하여
물체 위치로 이동하려고 하였으나 정상적으로 이동하지 않았다.

현재 자세에서 목표 위치까지 바로 이동하는 것이 원활하지 않았기 때문에,
RM75의 IP 조작 화면에 접속하여 로봇을 물체 방향으로 조금 더 가까운 위치까지
직접 이동시켰다.

그 후 다시 같은 `MoveJ_P` 동작을 실행하자 정상적으로 목표 위치로 이동하였다.

이를 통해 실기체에서는 목표 좌표만 설정하는 것이 아니라
**현재 로봇의 자세와 목표 사이에 실제로 이동 가능한 경로가 있는지도 중요하다**
는 것을 확인하였다.

또한 한 번에 큰 이동을 수행하기 어려운 경우에는
안전한 중간 자세를 거친 뒤 다시 목표 위치로 이동하는 방법이 효과적이었다.

---

## 5. 그리퍼 파지력 테스트

처음에는 다음 값으로 물체를 잡았다.

- Speed: `200`
- Force: `300`

Force 300에서도 물체를 잡는 것은 가능하였다.

하지만 물체를 잡은 상태에서 이동하거나 초기 자세로 복귀할 때
파지가 다소 불안정하게 느껴져 물체를 놓칠 위험이 있다고 판단하였다.

그래서 Speed는 그대로 유지하고 Force만 변경하여 다시 실험하였다.

### 두 번째 테스트

- Speed: `200`
- Force: `500`

Force를 500으로 높인 뒤 같은 동작을 다시 수행하였다.

그 결과 물체가 더 안정적으로 잡혔으며,
Force 500에서도 물체가 찌그러지는 현상은 발생하지 않았다.

따라서 이번 실습에서 사용한 물체에는

**Speed 200 / Force 500**

을 최종 파지값으로 선택하였다.

### 파지력 비교

| Speed | Force | 결과 |
|---:|---:|---|
| 200 | 300 | 파지는 가능했지만 이동 시 다소 불안정함 |
| 200 | 500 | 물체가 찌그러지지 않고 더 안정적으로 파지됨 |

Speed는 200으로 고정하고 Force만 300에서 500으로 변경하여
파지력에 따른 차이를 비교하였다.

---

## 6. A → B 이동

A 위치에서 물체를 파지한 뒤 들어 올려 B 위치로 이동하였다.

B 위치에서 사용한 좌표는 다음과 같다.

- x: `0.30`
- y: `0.14`
- z: `0.01`

A와 B 사이에서 주로 y 방향 위치를 변경하여
물체를 옆의 B 위치로 이동시켰다.

B 위치에 도착한 뒤에는 물체 방향으로 내려가
그리퍼를 열어 물체를 내려놓았다.

---

## 7. 전체 Pick-and-Place 동작

이번 실습에서 수행한 전체 흐름은 다음과 같다.

1. Home 자세에서 시작
2. 필요한 경우 IP 조작 화면에서 안전한 중간 자세로 이동
3. `MoveJ_P`로 A 위치 위까지 접근
4. `MoveL`로 수직 하강
5. Speed 200 / Force 500으로 물체 파지
6. 물체를 위로 들어 올림
7. A 위치에서 B 위치로 이동
8. B 위치에서 수직 하강
9. 그리퍼를 열어 물체 내려놓기
10. 다시 상승
11. Home 자세로 복귀

---

## 주의해야 할 점

### 1. 초기 자세에서 목표점으로 바로 이동하지 않기

초기 자세에서 `MoveJ_P`를 바로 실행했을 때
목표 위치로 정상적으로 이동하지 않는 경우가 있었다.

같은 명령을 계속 반복하기보다는
안전한 중간 자세로 이동한 후 다시 실행하는 것이 효과적이었다.

### 2. 물체에는 위에서 수직으로 접근하기

먼 거리에서는 `MoveJ_P`로 이동하고,
물체 가까이에서는 `MoveL`을 사용하여 수직으로 접근하였다.

이를 통해 테이블이나 물체와 부딪힐 위험을 줄일 수 있었다.

### 3. 파지 후 먼저 물체를 들어 올리기

물체를 잡은 뒤 바로 옆으로 이동하지 않고
먼저 위쪽으로 충분히 들어 올린 후 B 위치로 이동하는 것이 안전하다.

### 4. 파지력은 물체에 맞게 조정하기

파지력이 너무 약하면 이동 중 물체를 놓칠 수 있고,
너무 강하면 물체가 변형될 수 있다.

이번 실험에서는 Force 300보다 Force 500에서
물체의 변형 없이 더 안정적인 파지가 가능하였다.

---

## 배운 점

이번 실습을 통해 Pick-and-Place에서는 단순히 A와 B의 좌표를 정하는 것뿐 아니라
로봇이 목표까지 어떤 경로로 접근하는지가 중요하다는 것을 확인하였다.

특히 초기 자세에서 `MoveJ_P`를 바로 실행했을 때 동작이 원활하지 않았지만,
IP 조작 화면에서 로봇을 물체 가까이 이동시킨 뒤 다시 실행하자 정상적으로 동작하였다.

이를 통해 현재 로봇 자세와 목표 자세 사이의 이동 가능성,
안전한 중간 자세 설정의 중요성을 확인할 수 있었다.

또한 `MoveJ_P`와 `MoveL`을 상황에 따라 구분하여 사용하고,
Speed를 고정한 상태에서 Force를 300에서 500으로 변경해 비교하면서
안정적인 Pick-and-Place에는 좌표뿐 아니라 접근 방식과 파지 조건도
중요하다는 것을 배웠다.
