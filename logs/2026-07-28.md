배운 것
Gazebo를 이용하여 GO2 사족보행 로봇 시뮬레이션을 실행하는 방법을 배웠다.
RViz에서 RobotModel과 LiDAR(PointCloud)를 시각화하는 방법을 배웠다.
/cmd_vel 토픽을 통해 로봇의 이동 명령을 전달하는 방법을 배웠다.
teleop_twist_keyboard를 이용하여 키보드로 로봇을 조종하는 방법을 익혔다.
ros2 topic hz 명령어를 사용하여 토픽의 발행 주기를 확인하는 방법을 배웠다.
ros2 topic echo를 이용하여 토픽의 데이터를 확인하는 방법을 배웠다.
Gazebo에 장애물을 배치하고 LiDAR가 장애물을 인식하는 모습을 RViz에서 확인하였다.
ros2 topic pub 명령어를 사용하여 원하는 Twist 메시지를 직접 발행하는 방법을 배웠다.
ros2 bag info 명령어를 사용하여 rosbag 파일의 저장 정보와 토픽 정보를 확인하는 방법을 배웠다.
직접 해본 것 / 성공한 것
GO2 Gazebo 시뮬레이션을 실행하였다.
RViz에서 RobotModel과 LiDAR PointCloud를 정상적으로 출력하였다.
teleop_twist_keyboard를 실행하여 키보드로 GO2를 이동시켰다.
/cmd_vel 토픽을 확인하면서 이동 명령이 발행되는 것을 확인하였다.
/odom과 /velodyne_points 토픽의 발행 주기를 측정하였다.
Gazebo에 Box 장애물을 추가하고 RViz에서 LiDAR가 장애물을 감지하는 것을 확인하였다.
ros2 topic pub 명령어를 이용하여 전진 명령과 정지 명령을 직접 발행하였다.
LiDAR 데이터와 PointCloud를 모니터링하였다.
ros2 bag info를 이용하여 rosbag의 저장 시간, 메시지 수, 토픽 정보를 확인하였다.
실습 과정의 이미지와 동영상을 정리하여 GitHub에 업로드하였다.
막힌 것 / 이해가 어려웠던 것
처음에는 GO2가 기립하지 않고 바닥에 누운 상태로 실행되어 원인을 찾는 데 시간이 걸렸다.
RViz에서 LiDAR가 보이지 않아 Fixed Frame과 PointCloud 설정을 다시 확인하였다.
Gazebo에서 장애물을 추가한 뒤 RViz에 바로 반영되지 않아 토픽과 PointCloud 설정을 다시 확인하였다.
ros2 topic pub 명령어의 Twist 메시지 형식을 처음에는 익숙하지 않아 여러 번 수정하면서 실행하였다.
GitHub에 실습 자료를 정리하면서 파일 이름과 실습 순서를 맞추는 과정이 다소 헷갈렸다.
느낀 점

이번 실습을 통해 Gazebo와 RViz를 함께 사용하는 방법을 익힐 수 있었다. 특히 Gazebo에서 로봇의 움직임을 확인하고 RViz에서 
LiDAR 데이터를 동시에 확인하면서 ROS2의 토픽 기반 통신 구조를 이해하는 데 도움이 되었다. 또한 teleop, topic echo, topic hz, topic pub, rosbag 등 자주 사용하는 ROS2 명령어를 직접 사용해 보면서 각 명령어의 역할을 구분할 수 있었다. 앞으로는 SLAM이나 Navigation 실습에서도 이러한 기본 명령어를 활용할 수 있을 것 같다.
