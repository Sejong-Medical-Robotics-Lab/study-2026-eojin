## 배운 것

- Gazebo를 이용하여 GO2 사족보행 로봇 시뮬레이션을 실행하는 방법을 배웠다.
- RViz에서 RobotModel과 LiDAR(PointCloud)를 시각화하는 방법을 배웠다.
- `/cmd_vel` 토픽을 이용하여 로봇의 이동 명령을 전달하는 방법을 배웠다.
- `teleop_twist_keyboard`를 이용하여 키보드로 GO2를 조종하는 방법을 익혔다.
- `ros2 topic echo`를 사용하여 토픽의 데이터를 확인하는 방법을 배웠다.
- `ros2 topic hz`를 이용하여 토픽의 발행 주기(Hz)를 측정하는 방법을 배웠다.
- Gazebo에 장애물을 배치하고 RViz에서 LiDAR가 장애물을 인식하는 과정을 확인하였다.
- `ros2 topic pub` 명령어를 사용하여 Twist 메시지를 직접 발행하는 방법을 배웠다.
- `ros2 bag info`를 이용하여 rosbag 파일의 저장 정보와 토픽 정보를 확인하는 방법을 배웠다.

## 막힌 것 / 이해가 어려웠던 것

- 처음에는 GO2가 기립하지 않고 바닥에 누운 상태로 실행되어 원인을 찾는 데 시간이 걸렸다.
- RViz에서 LiDAR PointCloud가 보이지 않아 Fixed Frame과 Display 설정을 다시 확인하였다.
- Gazebo에서 장애물을 추가한 뒤 RViz에 바로 나타나지 않아 토픽과 PointCloud 설정을 다시 확인하였다.
- `ros2 topic pub` 명령어의 Twist 메시지 형식을 처음에는 이해하기 어려워 여러 번 수정하며 실행하였다.
- GitHub에 실습 자료를 정리하면서 파일 이름과 실습 순서를 맞추는 과정이 헷갈렸다.

## 느낀 점

이번 실습을 통해 Gazebo와 RViz를 함께 사용하는 방법을 익힐 수 있었다. Gazebo에서는 로봇의 움직임을 확인하고 RViz에서는 LiDAR PointCloud를 동시에 확인하면서 ROS2의 토픽 기반 통신 구조를 이해할 수 있었다. 또한 `teleop`, `topic echo`, `topic hz`, `topic pub`, `rosbag` 명령어를 직접 사용해 보면서 각각의 역할을 익힐 수 있었고, 앞으로 SLAM이나 Navigation 실습에서도 이러한 기본 명령어를 활용할 수 있을 것이라는 자신감을 얻었다.
