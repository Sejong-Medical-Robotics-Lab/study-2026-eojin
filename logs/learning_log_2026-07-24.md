# 학습일지 2026-07-24

## 오늘 배운 것

- ROS2에서 노드는 각각 하나의 역할을 담당하는 작은 프로그램이라는 것을 배웠다.
- 토픽은 센서 데이터나 속도 명령처럼 계속 전달되는 정보를 주고받을 때 사용하고, 서비스는 한 번 요청하고 응답을 받을 때 사용한다는 차이를 이해했다.
- `ros2 node list`, `ros2 topic list`, `ros2 node info`, `ros2 topic echo` 명령어를 이용해 실행 중인 ROS2 시스템을 확인하는 방법을 배웠다.
- turtlesim 실습을 통해 `geometry_msgs/msg/Twist` 메시지의 `linear.x`는 직진 속도, `angular.z`는 회전 속도를 의미한다는 것을 확인했다.
- ROS2 패키지는 워크스페이스의 `src` 폴더에 만들고, 수정한 뒤에는 `colcon build`와 `source install/setup.bash`를 실행해야 한다는 것을 배웠다.
- launch 파일을 이용하면 여러 노드를 한 번에 실행하고 종료할 수 있다는 것을 배웠다.
- tf2는 로봇의 몸체, 센서, 지도 등 여러 좌표계 사이의 관계를 관리하는 도구라는 것을 알게 되었다.

## 직접 해본 것 / 성공한 것

- turtlesim과 키보드 조종 노드를 실행해 거북이를 움직였다.
- `/turtle1/cmd_vel` 토픽을 확인하면서 키보드 입력에 따라 속도 값이 변하는 것을 관찰했다.
- `my_first_pkg` 패키지를 만들고 Python으로 ROS2 발행 노드를 작성했다.
- 패키지를 빌드하고 `/greeting` 토픽으로 메시지가 발행되는 것을 확인했다.
- launch 파일을 작성해 turtlesim 노드와 teleop 노드를 한 번에 실행했다.
- 작성한 코드와 학습일지를 GitHub에 커밋하고 푸시했다.


## 막힌 것 / 이해가 어려웠던 것

- 처음에는 패키지를 만들었는데도 `Package not found` 또는 `No executable found` 오류가 발생했다.
- 패키지를 수정한 뒤에는 다시 빌드해야 하고, 빌드 후에는 현재 터미널에서 `source ~/robot_ws/install/setup.bash`를 실행해야 한다는 것을 알게 되었다.
- `setup.py`의 `console_scripts`에 실행 파일을 정확하게 등록해야 `ros2 run`으로 실행할 수 있다는 것을 배웠다.
- launch 파일의 코드가 처음에는 복잡해 보였지만, 여러 노드를 한 번에 실행하기 위한 목록이라고 생각하니 이해하기 쉬웠다.

## 느낀 점

처음에는 ROS2 명령어가 많아서 어렵게 느껴졌지만, 직접 노드와 토픽을 확인하고 거북이를 움직여 보면서 각각의 역할을 조금씩 이해할 수 있었다. 하나의 프로그램이 모든 일을 처리하는 것이 아니라 여러 노드가 토픽을 통해 통신하며 하나의 로봇 시스템을 만든다는 점이 인상적이었다. 오류가 발생했을 때는 무작정 다시 실행하기보다 빌드와 source 여부를 먼저 확인해야 한다는 것도 배웠다.

## 한 줄 소감

ROS2 실습을 통해 여러 노드가 토픽으로 데이터를 주고받으며 로봇을 동작시키는 구조를 이해할 수 있었다.
