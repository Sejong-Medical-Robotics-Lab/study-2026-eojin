# 학습일지 — 2026-07-22 (Week 1, 공통교육 1일차)

## 오늘 배운 것 (3줄 요약)

- 로봇을 조작할 때는 멘토 동석, 비상정지 위치 확인, 안전거리 유지가 중요하다는 것을 배웠다.
- Ubuntu 터미널에서 `pwd`, `ls`, `cd`, `mkdir`, `cp`, `mv`, `grep` 등의 기본 명령어와 경로 사용법을 배웠다.
- Git과 GitHub에서 파일을 수정한 뒤 `add → commit → push` 순서로 기록하고 공유하는 방법을 배웠다.

## 직접 해본 것 / 성공한 것

- Ubuntu 22.04를 설치하고 터미널에서 폴더와 파일을 만들어 보았다.
- 쉘 스크립트 `new_exp.sh`를 작성하고 실행 권한을 부여해 실험 폴더가 자동으로 생성되는 것을 확인했다.
- GitHub에 개인 학습 저장소를 만들고 Git의 기본 명령어를 실습했다.
- ROS2 Humble을 설치하고 환경 설정을 진행했다.

## 막힌 것 / 이해가 안 되는 것

- 처음에는 현재 위치를 확인하지 않고 `cd` 명령어를 사용해서 `No such file or directory` 오류가 발생했다.
- `pwd`와 `ls`를 사용해 현재 위치와 폴더 이름을 확인하는 습관이 필요하다고 느꼈다.
- ROS2 저장소 등록 명령어가 길어서 각 명령어가 어떤 역할을 하는지 추가로 공부하고 싶다.

## 한 줄 소감

- 터미널 사용과  Git도 익숙하지 않아 버벅이는 부분이 많았지만, 직접 파일을 만들고 실행하는 과정을 반복하면서 처음보다 조금씩 익숙해질 수 있었다.
