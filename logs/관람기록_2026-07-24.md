# 시연회 관람 기록 2026-07-24
## 플랫폼별 한 줄 관찰

- **Go2:** 사족보행 로봇이 주행하면서 LiDAR 센서로 주변 환경을 인식하고, 해당 데이터가 rviz2 화면에 나타나는 모습이 인상적이었다.
- **G1:** 휴머노이드 로봇이 여러 관절을 동시에 움직이면서 균형을 유지하고 다양한 동작을 수행하는 모습이 신기했다.
- **FR3:** 로봇팔이 정해진 위치로 정확하게 이동하고, 사람이 힘을 가했을 때 부드럽게 반응하는 임피던스 모드가 인상적이었다.

## 오늘 배운 개념과의 연결

- Go2의 센서 데이터가 토픽으로 전달되고 rviz2에서 시각화되는 모습을 보면서, 오늘 배운 토픽과 시각화 도구가 실제 로봇에서도 사용된다는 것을 알 수 있었다.
- G1의 여러 관절 상태는 관절별 위치와 움직임 정보를 담은 메시지로 계속 발행될 것이라고 생각했다.
- FR3가 움직이기 위해서는 명령을 전달하는 노드, 경로를 계산하는 노드, 관절을 제어하는 노드 등이 서로 통신해야 한다고 생각했다.
- turtlesim에서는 간단한 노드와 토픽만 확인했지만, 실제 로봇에서는 훨씬 많은 노드와 토픽이 함께 동작한다는 것을 알게 되었다.

## 시연 중 생긴 질문

- G1은 여러 관절을 동시에 움직이면서 어떻게 중심을 잡고 넘어지지 않는지 궁금하다.

## 관람 소감

수업에서 배운 노드, 토픽, 메시지, rviz2 등의 개념이 실제 로봇에서 어떻게 사용되는지 직접 확인할 수 있어서 인상적이었다. turtlesim에서는 단순하게 보였던 통신 구조가 실제 로봇에서는 여러 센서와 관절을 제어하기 위해 복잡하게 연결된다는 것을 알게 되었다. 앞으로 플랫폼 실습을 진행하면서 각 노드와 토픽의 역할을 직접 확인해 보고 싶다.
